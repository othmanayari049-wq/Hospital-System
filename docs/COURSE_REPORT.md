# Course Project Summary

## Project title

Hospital Management System

## Course context

This application was developed as an educational project for an **Object-Oriented Programming course**. Its purpose is to demonstrate Java class design, inheritance, abstraction, interfaces, polymorphism, composition, collections, generics, exception handling, testing, and a layered architecture.

## Problem statement

Hospitals coordinate many connected activities: patient registration, staff assignment, appointments, medical records, rooms, admissions, prescriptions, inventory, bills, and payments. A software model must keep these responsibilities organised while protecting object state and preventing invalid operations.

## Implemented scope

- patient and staff management
- department and room management
- conflict-aware appointment scheduling
- educational medical-record and prescription entries
- admissions and discharges
- itemised bills and partial/full payments
- inventory and low-stock detection
- console interface
- read-only JavaScript dashboard served by Java
- seeded demonstration data and automated tests

## Out of scope

This project is not connected to a hospital, electronic health record, pharmacy, laboratory, insurer, or national health platform. It does not implement production authentication, privacy controls, encryption, clinical decision support, or regulatory compliance.
