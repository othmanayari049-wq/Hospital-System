# Contributing

This is an educational OOP course project. Contributions should keep the Java design clear and should not introduce real patient data.

## Development

1. Create a feature branch.
2. Run `mvn test`.
3. Keep domain rules inside entities or services, not in the UI.
4. Add tests for new business rules.
5. Use fictional or generated demonstration data only.

## Pull requests

Explain the OOP concept or system capability changed, include test evidence, and confirm that no patient-identifiable information is included.
